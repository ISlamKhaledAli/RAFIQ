طريقة تثبيت تحديثات ويندوز 7 SP1 المطلوبة لرفيق POS (بدون إنترنت)
Windows 7 SP1 prerequisite updates for Rafiq POS (offline)
=====================================================================

لماذا؟ بدون هذه التحديثات قد يفشل تثبيت .NET Framework 4.8 أو تظهر أخطاء التوقيع الرقمي (مثل 0x80040c01).

الترتيب الإلزامي حسب تعليمات مايكروسوفت (لا تغيّره):
  1) KB4490628  تحديث مكدس الخدمة (Servicing Stack Update - SSU)   ← أولاً
  2) KB4474419  دعم التوقيع الرقمي SHA-2                            ← ثانياً
  3) KB4019990  مكتبة D3DCompiler_47 (يحتاجها .NET Framework 4.8)  ← ثالثاً
  ثم أعد تشغيل الكمبيوتر (Restart).

الطريقة التلقائية (موصى بها):
  - ضع ملفات التحديثات بهذا الشكل داخل هذا المجلد:
        x64\KB4490628.msu   x64\KB4474419.msu   x64\KB4019990.msu    (لويندوز 64 بت)
        x86\KB4490628.msu   x86\KB4474419.msu   x86\KB4019990.msu    (لويندوز 32 بت)
    أعد تسمية ملف مايكروسوفت الأصلي (مثل windows6.1-kb4474419-v3-x64_....msu) إلى الاسم المطلوب بالضبط.
    السكربت لا يبحث في أي مجلد آخر ولا يقبل أي اسم آخر (لأسباب أمنية).
  - السكربت يتحقق من بصمة SHA256 لكل ملف قبل تثبيته. البصمات مكتوبة داخل السكربت نفسه،
    وأي بصمة تبدأ بكلمة UNVERIFIED تمنع التثبيت حتى يؤكدها مسؤول المشروع
    (إجراء التحقق في installer\prerequisites\README.md: تحميلان مستقلان، توقيع مايكروسوفت صالح،
    ومطابقة بصمة SHA1 الموجودة في اسم ملف الكتالوج الأصلي، ومراجعة شخص ثانٍ).
  - انقر بالزر الأيمن على «تثبيت_التحديثات_تلقائيا.bat» واختر «تشغيل كمسؤول».
  - السكربت يثبت التحديثات بالترتيب الصحيح ويتحقق من نتيجة كل تحديث:
        مثبت بنجاح / مثبت مسبقاً / غير مطلوب لهذا الجهاز / فشل (مع رمز الخطأ).
  - عند الانتهاء ستظهر رسالة بالعربية تسألك عن إعادة التشغيل. اختر «نعم».
  - سجل التفاصيل: %TEMP%\rafiq_win7_updates.log

الطريقة اليدوية:
  - اعرف نواة جهازك: ابدأ ← كمبيوتر (زر أيمن) ← خصائص ← نوع النظام (32 أو 64 بت).
  - اضغط مرتين على KB4490628 وثبته، ثم KB4474419، ثم KB4019990 (من مجلد النواة الصحيحة).
  - أعد تشغيل الكمبيوتر.

بعد إعادة التشغيل: شغّل ملف تثبيت رفيق RafiqPOS_Setup؛ سيثبت .NET Framework 4.8 تلقائياً بدون إنترنت إذا لم يكن موجوداً.
