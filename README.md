# رفيق — نظام إدارة نقاط البيع والسوبرماركت (Rafiq POS)

نظام متكامل لنقاط البيع وإدارة محلات التجزئة والسوبرماركت مصمم للعمل بدون اتصال إنترنت (Offline-First) مع أمان مالي صارم وتوافق كامل وشامل من **Windows 7 SP1 (32/64-bit)** وحتى **Windows 11**.

---

## 🏗️ المعمارية الهندسية (Architecture Stack)

* **المضيف ونواة النظام (Host Backend):** مكتوب بلغة **C# (.NET Framework 4.8)** لضمان استهلاك ذاكرة منخفض جداً (RAM < 150MB) والتحكم المباشر في الطرفيات (طابعات الفواتير الحرارية ESC/POS وقارئات الباركود والموازين الإلكترونية).
* **واجهة المستخدم (Frontend UI):** مبنية بـ **React 18 + TypeScript + Vite + Tailwind CSS 3.4** وموجهة لـ Chromium 109 مع دعم كامل للغة العربية (RTL).
* **محرك العرض (Desktop Browser Engine):** **Microsoft WebView2** (يدعم النسخة الثابتة Fixed Version 109 على Windows 7 و 8.1، والنسخة Evergreen على Windows 10 و 11).
* **قاعدة البيانات (Database):** **SQLite 3** مدمجة مع تفعيل وضع سجل الكتابة المسبق **Write-Ahead Logging (WAL)** للحماية القصوى ضد انقطاع الكهرباء الفجائي.
* **الحسابات المالية (Financial Integrity):** جميع الأسعار والمبالغ تُخزّن **بالقروش كأعداد صحيحة (Integers)** لمنع أخطاء التقريب العشري.
* **برنامج التثبيت (Packaging):** **Inno Setup 6** لإنتاج ملف تثبيت مستقل واحد (Single Setup .exe) يفحص المتطلبات المسبقة ويحمي بيانات العميل.

## 📂 هيكل المشروع (Project Structure)

```
RAFIQ/
├── ARCHITECTURE_AND_PLAN.md    # وثيقة المعمارية الهندسية الشاملة
├── PROJECT_BACKLOG.md          # سجل المهام والقصص (12 محطة و 413 مهمة)
├── دليل_تثبيت_وتجربة_ويندوز7.md # دليل النقل والتثبيت على أجهزة ويندوز 7
├── frontend/                   # كود واجهة المستخدم (React + Vite + Tailwind)
├── desktop/                    # كود النواة (C# WinForms + WebView2 + SQLite)
├── installer/                  # اسكربت ومخرجات برنامج التثبيت (Inno Setup)
├── تشغيل_رفيق.bat              # تشغيل البرنامج المكتبي مباشرة بضغطة زر
├── تشغيل_وضع_المطور.bat        # تشغيل واجهة الويب في وضع التطوير (Dev Mode)
└── انشاء_ملف_التثبيت_Setup.bat # بناء ملف التثبيت المجمع آلياً
```

## 🚀 التشغيل السريع (Quick Start)

### 1. تشغيل التطبيق المكتبي:
اضغط مرتين على ملف:
`تشغيل_رفيق.bat`

### 2. تشغيل واجهة التطوير في المتصفح:
اضغط مرتين على ملف:
`تشغيل_وضع_المطور.bat`

### 3. بناء ملف التثبيت المجمع (.exe):
اضغط مرتين على ملف:
`انشاء_ملف_التثبيت_Setup.bat`
وسيقوم آلياً ببناء الواجهة والمضيف وتجميع مثبت `installer/Output/RafiqPOS_Setup_v1.0.0.exe`.
