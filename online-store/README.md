# متجر رفيق الإلكتروني (Rafiq Online Store)

مشروع سحابي متكامل ومستقل لتحويل أي محل يستخدم نظام رفيق لنقاط البيع (Rafiq POS) إلى متجر إلكتروني فوري بنقرة واحدة.

---

## 1. الهيكل المعماري (Architecture)

```
online-store/
├── api/                   # خادم السحابة (Cloudflare Workers + D1 Database + R2)
│   ├── schema.sql         # مخطط قاعدة البيانات السحابية (D1 SQLite)
│   ├── wrangler.toml      # إعدادات ونشر Cloudflare Worker
│   ├── src/
│   │   ├── index.ts       # موجه الطلبات الرئيسي ودعم CORS
│   │   ├── auth.ts        # مصادقة مزامنة الكاشير ودخول المشرف
│   │   ├── crypto.ts      # تشفير SHA-256 والتوكنات الآمنة
│   │   └── handlers/
│   │       ├── sync.ts    # واجهات مزامنة نقاط البيع (Catalog, Stock, Sales, Orders)
│   │       ├── store.ts   # واجهات المتجر الإلكتروني للزبائن والشراء وتتبع الطلب
│   │       └── dashboard.ts # واجهات لوحة تحكم صاحب المحل عن بعد
│   └── test/              # اختبارات الوحدة التلقائية (15 اختبار بذاكرة SQLite)
│
└── web/                   # واجهة المتجر الإلكتروني ولوحة التحكم (React + Vite + Tailwind)
    ├── src/
    │   ├── App.tsx        # المكون الرئيسي للمتجر
    │   ├── api/client.ts  # عميل الاتصال بالسيرفر مع وضع التجربة الفوري
    │   └── components/    # مكونات السلة، العرض، الدفع، التتبع، والداشبورد
    └── dist/              # حزمة الإنتاج الجاهزة للرفع على Cloudflare Pages
```

---

## 2. كيفية تشغيل المشروع وتجربته محلياً

### أ) تشغيل واجهة المتجر الإلكتروني (Web Storefront):
```bash
cd online-store/web
npm run dev
```
سيعمل الموقع على المتصفح على: `http://localhost:3000`

### ب) تشغيل خادم الـ API واختباراته:
```bash
cd online-store/api
npm test
```
لتشغيل الخادم محلياً عبر محاكي Cloudflare Wrangler:
```bash
npx wrangler dev
```

## 3. الضمانات الهندسية (Engineering Invariants)
- **الأمان المالي:** حساب كافة الأسعار والمبالغ ورسوم التوصيل والخصومات بالقروش (`price_piasters` كأعداد صحيحة `INTEGER`) دون أي استخدام للأعداد العشرية العائمة (`float/double`).
- **العزل التام:** تطبيق الديسكتوب الحالي (`desktop/`) وبرنامج الكاشير أوفلاين لم يُمس بأي تعديل، ويعمل بشكل مستقل تماماً.
- **حماية البيانات الحساسة:** واجهات المتجر العامة لا تُرجع أبداً تكلفة المنتجات (`cost_piasters`) أو مفاتيح المزامنة والترخيص.
- **تصميم متجاوب:** يدعم الموبايل والشاشات اللمسية، مع هوية بصرية مخصصة تدعم تغيير الثيمات (كلاسيك أخضر، أزرق طبي، بني دافئ، أحمر حيوي، داكن أنيق).
